# 🌙 Moon Lockpick

پلاگین **Moon Lockpick** یک پلاگین Minecraft برای Paper است که با هدف اضافه‌کردن مکانیک Lockpicking و تعامل جذاب‌تر با قفل‌ها و صندوق‌ها طراحی شده است.

## ✨ ویژگی‌ها

- سیستم Lockpicking برای باز کردن قفل‌ها
- ساختار آماده برای توسعه و اضافه‌کردن مکانیک‌های جدید
- ذخیره‌سازی اطلاعات با SQLite
- مناسب برای سرورهای Paper
- تنظیمات قابل توسعه از طریق `config.yml`

## 📦 نصب

1. فایل JAR ساخته‌شده را در پوشه `plugins` سرور Paper قرار دهید.
2. سرور را ری‌استارت کنید.
3. فایل‌های تنظیمات پلاگین در پوشه مربوط به پلاگین ساخته می‌شوند.

## 🔨 ساخت از سورس

پروژه با Maven ساخته می‌شود و به Java 17 نیاز دارد:

```bash
mvn clean package
```

پس از Build، فایل JAR در پوشه `target` قرار می‌گیرد.

## ⚙️ نیازمندی‌ها

- Java 17+
- Paper 1.20.4 یا سازگار
- Maven 3.8+

## 📁 ساختار پروژه

```text
lockpick-plugin/
├── src/
│   └── main/
│       └── resources/
│           ├── plugin.yml
│           └── config.yml
└── pom.xml
```
